# Homebrew Tap for Datara & Forgen

Official Homebrew tap for the [Datara Programming Language](https://github.com/datara-lang/datara) and the Forgen native compiler.

## Installation

`ash
brew tap datara-lang/tap
brew install datara
`

Or install in a single command:

`ash
brew install datara-lang/tap/datara
`

## Verify Installation

`ash
forgen --version
datara --version
`
